# 🔢 MNIST Handwritten Digit Prediction App

A deep learning project that predicts handwritten digits using the MNIST dataset with TensorFlow and deploys the model through an interactive Streamlit web application.

The project includes model training, model dumping (.h5), custom image preprocessing, and real-time digit prediction from uploaded images.

This project is a deep learning-based web application that predicts handwritten digits using the famous MNIST dataset.

The model was trained using TensorFlow/Keras and deployed using Streamlit for real-time image prediction.

## 🚀 Features
- Upload handwritten digit images
- Automatic image preprocessing
- Real-time digit prediction
- Confidence score display
- Streamlit interactive UI

## 🛠 Technologies Used
- Python
- TensorFlow / Keras
- Streamlit
- NumPy
- PIL

## 📌 Project Workflow
1. Train CNN model on MNIST dataset
2. Save trained model (`mnist_model.h5`)
3. Create custom preprocessing function
4. Build Streamlit application
5. Predict uploaded handwritten digits
